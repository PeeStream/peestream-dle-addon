# Contributing to PeeStream for DataLife Engine

Thank you for helping improve the PeeStream ecosystem.

## Reporting an issue

- Check [existing issues](https://github.com/PeeStream/peestream-dle-addon/issues) first.
- Include the addon, DLE, PHP, and database versions and say whether the system is staging or production.
- Provide reproducible steps and logs with personal information and credentials removed.
- Report security vulnerabilities privately; see [SECURITY.md](SECURITY.md).

## Pull requests

1. Discuss behavior changes before implementing large features.
2. Avoid changing production configurations, default auto-publishing behavior, or user data without explicit consent.
3. Include tests and identify all mocked or simulated CMS behavior.
4. Treat plugin-manager installation and upgrade compatibility as unverified until tested in an actual licensed DLE staging installation.
5. Keep public documentation and development communication in professional English.

Never commit live secrets, server credentials, or runtime-generated configuration files.
